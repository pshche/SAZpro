### с какими проблемами столкнулся и исправил:

в дефолтном (Не ПРО) Dojo есть проблема лицензии Cyclone DX там есть Cyclone Dx Scan для него нужен файл Vex тогда он оттриажит это (можно сделать через trivy с флагом vex иначе он не может сопоставить)

trivy image --scanners vuln --format cyclonedx \
  --output reports/sca/juice-shop-vex.cdx.json \
  bkimminich/juice-shop

такой формат dojo Cyclone DX Scan примет и покажет findings
иначе (только через curl получится понять) что нужна про лицензия

возможно это стоит пояснить в задачах

вместо
curl -X POST "http://localhost:8088/api/v2/import-scan/" \
  -H "Authorization: Token 19d0e9c8d151f2f763f4ba19b824fb718721a685" \
  -F "scan_type=CycloneDX Scan" \
  -F "engagement=11" \
  -F "file=@reports/sca/juice-shop.cdx.json"

это
curl -X POST "http://localhost:8088/api/v2/import-scan/" \
  -H "Authorization: Token 19d0e9c8d151f2f763f4ba19b824fb718721a685" \
  -F "scan_type=CycloneDX Scan" \
  -F "engagement=11" \
  -F "file=@/Users/ps/SAZ/saz-lab/reports/sca/juice-shop-vex.cdx.json;type=application/json"

для этого надо через триви с флагом vex получить juice-shop-vex.cdx.json
